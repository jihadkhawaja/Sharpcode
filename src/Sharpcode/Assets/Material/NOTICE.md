# Material Icon Theme artwork

These explorer icons are 32 px PNG exports from [Material Icon Theme at commit 310f68f](https://github.com/material-extensions/vscode-material-icon-theme/tree/310f68fe3a12388b0ecde03bf73843d250997ff5/icons). The upstream artwork was rendered from its SVG source with resvg. Sharpcode maps the bundled subset to its own file and folder names.

The upstream project credits [Material Design Icons](https://pictogrammers.com/library/mdi/) and [Material Symbols](https://fonts.google.com/icons) as icon sources.
